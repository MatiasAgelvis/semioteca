# CV dossier (2015)

Scanned documents from Valmore Agelvis's 2015 academic dossier (job application).
Kept for reference only — **not published on the site**.

The public CV (`/cv`) is a text page built from these documents. They live here
instead of `backend/CV` because `scripts/sync-content.mjs` copies `backend/CV`
into the deployed `frontend/static/content`.
